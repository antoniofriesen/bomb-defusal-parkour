Bomb Defusal Parkour

About this mockup: Rough concept for Checkpoint 1, not the final visual design (no styling polish yet).

Every data-field attribute on an element maps to a field defined in the ICD (docs/ICD_Bomb_Defusal_Parkour.md) - this is how the mockup ties its UI elements back to the actual data model. Each station card carries data-station-id (matching the ICD's station_id) - in real code, an incoming MQTT message's station_id is the key used to find the right card, then state/rating update the fields inside it.
